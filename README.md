Production portfolio showcasing end-to-end agentic systems, Model Context Protocol (MCP) tool design, LiveKit WebRTC realtime voice, multi-tier LLM routing harnesses, pgvector retrieval pipelines, and AWS EKS cloud infrastructure.

## Stack
- **Framework:** React 19 + Vite 6
- **Styling:** Tailwind CSS v4
- **Icons:** Lucide React + Bespoke SVGs
- **Deployment:** GitHub Pages (`https://mraj602.github.io`), served from the `gh-pages` branch — publish with `pnpm run deploy`

## Development

pnpm install
